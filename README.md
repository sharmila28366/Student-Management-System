# Student Management System

## 1. Project Description

The Student Management System is a full-stack web application developed to manage student information efficiently.

The application allows users to add, view, update, delete, and search student records through a simple and user-friendly web interface.

This project follows the CRUD (Create, Read, Update, Delete) concept and uses REST APIs for communication between the frontend, backend, and database.

## 3. Features

- Add new student records
- View all student records
- View individual student details
- Update student information
- Delete student records
- Search students by name
- Email validation
- Year validation
- Phone number validation
- Duplicate email validation
- REST API integration
- Responsive user interface

---

## 4. Student Details

The system stores the following information:

- Student ID
- Name
- Email
- Department
- Year
- Phone Number

The Student ID is automatically generated by the database.

---

## 5. CRUD Operations

| Operation | HTTP Method | API Endpoint |
|---|---|---|
| Create Student | POST | `/api/students/` |
| View All Students | GET | `/api/students/` |
| View Single Student | GET | `/api/students/<id>/` |
| Update Student | PUT | `/api/students/<id>/` |
| Delete Student | DELETE | `/api/students/<id>/` |
